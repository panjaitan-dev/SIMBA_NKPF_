## 5. Panduan Pengaturan Alat Pengembang (Pencegahan Trailer Otomatis)

Agar commit di masa mendatang tidak secara otomatis menyisipkan trailer kolaborasi AI (`Co-Authored-By`), pengembang disarankan menerapkan konfigurasi berikut pada lingkungan lokal:

1. **Claude Code CLI:**
   Nonaktifkan penyertaan co-author otomatis dengan perintah:
   ```bash
   claude config set -g includeCoAuthor false
   ```
   Atau pastikan pada berkas konfigurasi pengguna `~/.claude.json` bernilai:
   ```json
   {
     "includeCoAuthoredBy": false
   }
   ```

2. **VS Code & Cursor IDE:**
   Pada setelan `settings.json` (Pengguna / Workspace):
   ```json
   {
     "git.showCommitInputCoAuthors": false,
     "github.copilot.chat.commitMessageGeneration.includeCoAuthors": false
   }
   ```

3. **GitHub Desktop:**
   Masuk ke menu **Options / Preferences** -> **Git** -> Pastikan opsi penambahan rekan penyunting (*co-authors*) tidak dicentang saat membuat commit.

4. **Git Hook Repositori:**
   Direktori `.git/hooks/` repositori ini bersih dari hook aktif (`commit-msg` atau `prepare-commit-msg`), sehingga tidak ada injeksi trailer tersembunyi.
