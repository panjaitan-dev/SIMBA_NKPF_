Pencarian dilakukan secara sensitif huruf besar-kecil (*case-insensitive*) dan pencarian pola regex terhadap seluruh berkas repositori. Daftar istilah yang dicari disimpan dalam bentuk terenkode (Base64) di skrip regresi untuk menghindari positif palsu pada pencarian teks.

### Cakupan Wilayah Pemeriksaan:

4. **(d) Berkas Khusus Alat & Folder Asisten:** Berkas konfigurasi dan instruksi bawaan editor/asisten pengembang.
5. **(e) Aset Grafis & Multimedia:** Metadata biner chunk PNG (`tEXt`, `zTXt`, `iTXt`, `eXIf`), komentar dan tag metadata XML SVG, berkas video `animasi.mp4`, favicon, dan penelusuran PDF.

## 5. Panduan Pengaturan Alat Pengembang (Pencegahan Trailer Otomatis)

Agar commit di masa mendatang tidak secara otomatis menyisipkan trailer kolaborasi, pengembang disarankan menerapkan konfigurasi berikut pada lingkungan lokal:

1. **Alat CLI Pengembang:**
   Nonaktifkan penyertaan co-author otomatis sesuai dokumentasi resmi masing-masing alat.

2. **VS Code & Editor IDE:**
   Pada setelan `settings.json` (Pengguna / Workspace):
   ```json
   {
     "git.showCommitInputCoAuthors": false
   }
   ```

3. **GitHub Desktop:**
   Masuk ke menu **Options / Preferences** -> **Git** -> Pastikan opsi penambahan rekan penyunting (*co-authors*) tidak dicentang saat membuat commit.

4. **Git Hook Repositori:**
   Direktori `.git/hooks/` repositori ini bersih dari hook aktif (`commit-msg` atau `prepare-commit-msg`), sehingga tidak ada injeksi trailer tersembunyi.
